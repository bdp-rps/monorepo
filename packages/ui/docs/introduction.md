The BdP LV RPS Styleguide is a framework for building front-end applications using React.

## What's included?

- Primitive core components (e.g. Box, Text)
- Layout components (e.g. Modal, Card, Grid, Row, ScrollView)
- Action components (e.g. Button, TabNav/TabNavItem, Link)
- Form components (e.g. TextInput, SelectInput, Toggle)
- Composed CI components (e.g. Tile)

## Browser Support

- Internet Explorer 11, Edge 17
- Safari 11.1, iOS Safari 11.3
- Chrome 66, Chrome Android 66
- Firefox 60, Firefox Android 66
