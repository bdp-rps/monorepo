Link is used for hyperlink creation.

If used with Next.js, make sure to add the `passHref` prop to `next/link`.

### Basic Usage

```jsx
<Box space={2}>
  <Link action="/link">Just a link</Link>
</Box>
```

### Disabled

```jsx
<Box space={2}>
  <Link disabled href="/link">
    Just a link
  </Link>
</Box>
```
